# 易绘上架工作台

易绘上架工作台是一套本地 Electron 桌面应用，用于管理电商商品资料、类目属性模板、AI 图片与标题生成，并通过妙手完成商品录入、回写和发布流程。

当前发布版本：`v0.2.0`
Windows 安装包：[GitHub Releases](https://github.com/wumingyuanxxx/test-upload-v2/releases)

## 主要能力

- 商品工作台：商品查看、编辑、复制到当前店铺、图片管理和删除。
- 类目与属性模板：维护常用类目、类目属性模板、产地等基础属性，并可手动回填至商品。
- 智能提示词模板：按标题、详情图、类目生图、包装、说明书等类型管理模板并绑定类目。
- 上架自动化：按配置执行标题生成、轮播图生成、录入妙手、回写与发布；标题和轮播图均支持优先使用类目绑定模板。
- 文件夹建品：从本地文件夹创建商品草稿，应用类目属性模板并衔接上架自动化。
- 以图建品（桌布）：上传 1–6 张展示图，生成原图与多张轮播图；支持任务分页、图片预览、左右切换、重新生成、删除生成结果、批量下载和创建商品。
- AI 图片能力：图库上传、AI 改图、生成记录追踪，以及多个模型供应商与图片适配器配置。
- 妙手集成：授权店铺同步、采集箱同步、预发布店铺认领、商品录入、回写和发布记录。

## 技术栈

- Electron 35
- Node.js
- MySQL（`mysql2`）
- 阿里云 OSS（`ali-oss`）
- `electron-builder`（Windows NSIS 安装包）

## 运行环境

- Windows 10 / 11 x64
- Node.js 18 或更高版本
- 可访问的 MySQL 数据库
- 已配置的 OSS（用于上传源图与保存 AI 生成图）
- 如需妙手、AI 标题或 AI 生图能力，需在应用内补充对应服务配置

## 本地运行

```bash
npm install
npm start
```

首次启动后，在应用的系统设置中完成以下配置：

1. 数据库连接并初始化数据表。
2. OSS 连接与测试。
3. 妙手 API 账号配置、启用账号并同步授权店铺。
4. 大模型供应商配置：填写 API Base URL、API Key、默认模型、接口类型和图片模型适配器。

仓库和安装包不包含生产凭据。API Key 按当前产品设计由用户在系统设置中录入并保存于本地数据库；请限制数据库访问权限，并为 OSS 等服务配置最小权限凭据。

## 使用流程

### 商品与自动化

1. 创建商品或使用文件夹建品、以图建品生成商品草稿。
2. 选择常用类目，确认类目属性模板的回填结果。
3. 在“上架自动化”中设置标题、轮播图、录入、回写、发布等步骤。
4. 配置目标平台、站点和预发布店铺后执行自动化。
5. 在录入记录、写入记录和生成记录中查看处理结果与失败信息。

### 以图建品 · 桌布

1. 在“以图建品 · 桌布”保存原图模型、原图提示词、轮播图模型、轮播图提示词和货号规则。
2. 上传 1–6 张商品展示图，创建任务。
3. 任务依次生成原图和每个已选轮播图模板对应的轮播图。
4. 在任务详情中可放大预览、左右切换、删除指定生成图，或单独重新生成原图/轮播图。
5. 选择常用类目并点击“创建商品”，系统会创建本地草稿、回填属性模板，并衔接已启用的上架自动化。

## 检查与打包

语法检查：

```bash
npm run check
```

构建 Windows x64 NSIS 安装包：

```bash
npm run dist
```

构建输出位于 `release/`，默认安装包名称为：

```text
易绘上架工作台 Setup <版本号>.exe
```

安装版会从本仓库的 GitHub Releases 检查更新。发现新版本后，可在“系统设置 → 关于与更新”中下载，并选择重启安装。

## 数据与安全说明

- 应用会在本地配置的 MySQL 数据库中保存业务数据、模型配置、自动化配置与执行记录。
- 默认本地工作台账号为 `root / 123456`，部署后建议根据使用环境自行修改。
- `database/schema.sql` 仅包含表结构和默认本地工作台账号，不包含第三方服务配置或业务数据。
- 图片会根据业务流程上传至配置的 OSS，并在图库或任务记录中保存 URL 引用。
- 删除任务中的生成图只会解除任务关联，不会删除 OSS 原文件或已创建商品中的图片数据。
- 对生产数据库执行初始化或配置变更前，请先完成备份。
